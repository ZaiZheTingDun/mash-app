# 从者退场规则

`src-tauri/src/resources/change_order_servants.json` 是手动维护的静态规则表，由前端阵容预览和 Rust 战斗阵容回放共同读取；从者资源更新不会自动更新此表。`source` 是人工核查线索，不参与规则执行。

`withdrawSelfToBack` 表示移至替补队尾，不是与首个替补交换。例如 `[鹤, A, B, C, D, E]` 变为 `[C, A, B, D, E, 鹤]`。克莱恩小姐在宝具结算时触发，泳装克洛伊在二技能使用回合结束时触发。场上仅剩自身时不撤退。没有替补时，下一回合阵容沿用原排列；暂时离场期间的敌方目标选择不在此阵容推演模型内。
