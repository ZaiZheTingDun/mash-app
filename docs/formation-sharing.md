# 编队快速分享

在编队、指令或运行设置页的当前队伍旁点击「分享」，生成并复制一串标准 Base64。复制失败时提供完整文本供手动复制。「粘贴编队」在没有当前队伍时也可使用，设置的队伍管理页提供相同入口。

导入先预览成员、自有／助战身份、礼装、助战要求及普通与高级指令，再确认名称及目标分组。始终创建新队伍；不覆盖原队伍，不启动运行，运行设置固定为单次且不自动补充体力。

## 数据边界

包含六个槽位、从者图鉴号及变体、礼装与候选列表、满破要求、助战练度要求、御主礼装、冠位角色及选卡策略、普通与高级两套指令，以及自动技能目标识别和暴击率优先等执行选项。行动、条件、目标和换人顺序均保留。

不记录来源服务器／区服、来源项目 ID、应用版本、设备、路径、日志、识别阈值、循环或补充体力偏好。项目级助战职阶筛选模式影响候选选择，因此随方案保留。

资源使用已有的稳定 collection number 和从者变体标识。接收方保持自己的区服设置，并用本地资源目录解析名称。无法识别的资源保留原编号并提示，不静默删减。目录可识别不代表账号持有，也不保证不同客户端的技能效果和实战结果相同。

## 封装协议 v1

```text
标准 Base64（保留填充符）
└─ 10 字节协议头 + Gzip 数据
   └─ UTF-8 紧凑 JSON
```

| 字节偏移 | 长度 | 内容 |
| --- | ---: | --- |
| 0 | 4 | ASCII `MASH` |
| 4 | 1 | 容器版本，当前为 `1` |
| 5 | 1 | 压缩算法，`1` 为 Gzip |
| 6 | 4 | JSON 原始字节数，大端序 |

Gzip 时间戳固定为零，实际解压大小必须与声明一致，并通过 Gzip 校验。不接受尾随数据或多个 Gzip 成员。Base64 外层允许 ASCII 空白和换行。

JSON 信封示意：

```json
{"v":1,"f":[],"c":{},"x":{"note":"可选的展示注记"}}
```

- `v`：配置结构版本，与容器版本独立。
- `f`：必需功能编号列表。
- `c`：紧凑配置，包含 `p`（项目）、`b`（普通指令）、`ab`（高级指令）。
- `x`：可忽略的展示信息，正常导出不写入。执行逻辑不能放在这里。

容器、结构、字段及功能编号一旦发布，不可重新解释或复用。未知容器／结构版本和必需功能提示升级；未知执行字段、行动或选项必须拒绝，只有 `x` 区域允许忽略未来展示信息。

| 功能编号 | 含义 |
| --- | --- |
| 1 | 高级指令文档 |
| 2 | 冠位配置与规则 |
| 3 | 技能追加选择 |
| 4 | 暴击／自定义选卡策略 |
| 5 | 项目级助战职阶筛选 |

完整字段字典及 v1 默认值位于 `src-tauri/src/formation_share/wire.rs`，不随内部模型默认值变化。应用模型新增字段时必须明确分类为可分享或本地字段，未分类字段会阻止导出，避免战术数据被意外遗漏。

## 身份与持久化

项目内成员和行动标识在传输时变成短整数，解码后恢复为项目作用域内稳定标识。编号不等于站位或图鉴号。同一图鉴号的自有从者与助战是不同成员。

所有 `memberId`、`servantMemberId`、`targetMemberId`、`frontMemberId`、`backMemberId` 引用统一转换，覆盖技能、目标、换人、宝具、条件和策略。引用必须存在，图鉴号及助战元数据须与成员一致。旧版位置字段保留，供已有兼容逻辑读取。

协议模块只处理内存中的白名单提取、短字段转换、压缩与校验，不依赖 Tauri、区服、目录或文件系统。应用适配器负责模型迁移、预览、剪贴板及提交；React 只管理草稿、加载状态和展示。

前端等待当前项目的相关保存全部完成，失败时阻止分享旧数据；重排的项目与两类指令保存作为同一组等待。后端项目、目录及指令命令共用 `ProjectStoreLock`，分享在锁内读取快照。

预览 token 绑定不可变配置，最多八份，十五分钟失效。编辑输入或关闭对话框时丢弃旧 token。提交时重新检查命名和分组；成功后才消费 token，失败可修正后重试。

文件与分享码导入共用提交管线：暂存两类指令，发布完整队伍目录，更新分组，最后原子替换项目列表作为可见性边界。失败清理新目录；列表提交失败时恢复原始目录文件。突然中断发生在列表提交前时，新文件不会成为可见队伍。

## 限制与验证

- 输入最多 128 KiB，实际解压 JSON 最多 1 MiB。
- 六个成员槽位、一个助战，成员标识唯一、引用有效。
- 最多一百面，单数组最多一千项，总节点最多二万五千，领域结构最多六十四层。
- 拒绝重复 JSON 键、非法枚举、越界参数、损坏或不兼容数据。
- 字符数为 `4 × ceil((10 + Gzip字节数) / 3)`，不自动截断或删除方案内容。

`src-tauri/src/formation_share/fixtures/v1.txt` 是固定历史兼容样例。测试覆盖同从者助战、换人、高级条件、运行偏好排除、未知语义拒绝、有界解压、过期／重复 token 和提交失败恢复。另有六成员、六礼装、三面十二次技能的完整模型往返及容量预算测试。

该完整模型模拟样例目前生成 504 个 Base64 字符。名字、资源编号、助战要求、技能选项和额外规则均影响压缩结果，不能将此数值视为所有同规模真实编队的固定长度。

原生剪贴板通过 Rust 的 Tauri 插件写入，未给前端增加通用剪贴板权限。实际 Windows/macOS 剪贴板行为需在平台验收时确认；普通单元测试和浏览器界面检查不依赖 ADB。
