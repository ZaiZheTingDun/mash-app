# 礼装加成简化展示（资源 v18）

礼装选择器由 Rust 的 `craft_essence_picker` 读取当前服务器精简数据并计算推荐，前端只渲染后端返回的文字和图标。活动有效期和助战数值沿用各自数据，界面只显示满破时的加成数值，不显示「满破：」前缀，不再使用整段技能说明。名称、加成和卡面在同一行，加成位于卡面左侧；超长加成以省略号收起，悬停可查看完整内容。推荐资格仍根据全部加成判断，不受展示筛选影响。行高保持 40px。

推荐顺序：当前活动加成礼装在前；之后依次为迦勒底午茶时光（910）、迦勒底午餐时光（330）、贝拉·丽莎（988）、蒙娜丽莎（80）；其他礼装按满破时自身的百分比牵绊加成从高到低排序，仅有助战加成时使用助战百分比。同百分比按收藏编号排序，其他百分比量子礼装排在牵绊礼装之后。当前/未来活动的判断随时间更新，活动结束后礼装恢复常驻排序。

`src-tauri/src/resources/craft_essence_bonus_labels.json` 是手动维护的 ID 映射：

- `traits` 根据已有国服礼装说明提取中文简称，并记录来源地区和礼装收藏编号；国服没有的条件按日服说明补录。所罗门分支来自日服函数条件及对应从者名称。
- 多个 `functvals` 为“或”；`overWriteTvalsList` / `script.overwriteTvals` 的同一组为“且”，组之间为“或”。界面保留这些关系。
- `rewardFunctions` 保存少量需要补充显示的关卡范围，`eventTargets` / `progressTargets` 保存敌人及进度分类简称。
- 后续新增 ID 先显示“条件#ID”，补录映射后再显示中文，运行时不从原始说明猜测条件。

道具数据来自资源包 `events/items.json`；名称优先国服，日服独有素材用日服名称。图片直接使用礼装函数组 `group.icon` 对应的共用 `icons/items/*.png`。不再通过道具特性或 `targetId` 反查图片；缺少关联或图片时显示素材名称（无法确定名称时显示“活动素材”）。

只保留当前/未来活动的索引，打开时按当前时间选择有效效果；资源安装后失效缓存。已有“仅推荐百分比牵绊/量子”的资格规则保持不变，固定数量不会因此加入推荐。

御主经验由精简资源的 `masterExpBonuses` 提供，来自 `expUp`，不包含魔术礼装经验。仅用于补充详情，不改变推荐资格或牵绊排序；有满破版本时使用满破数值，没有满破版本的常驻效果使用全程生效的普通数值。旧资源缺少该字段时保持兼容，需要更新或重新导入含该字段的资源后才显示。

魔术礼装经验来自 `mysticCodeExpBonuses`（`userEquipExpUp`），与御主经验独立展示；同样支持百分比、固定数量、助战和适用条件，并采用满破或全程不变的效果，不改变推荐资格及排序。

友情点数来自 `friendPointBonuses`，保留 `friendPointUpDuplicate` 的可叠加标记，仅补充详情。满破效果筛选统一支持没有独立满破版本的常驻技能，因此 1976 等 FSN 从者牵绊礼装会正常显示，FSN「英灵逢魔」系列（1973–1979）统一放在推荐列表最后，系列内按收藏编号排序。
