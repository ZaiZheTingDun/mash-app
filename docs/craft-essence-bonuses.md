# 礼装加成展示

礼装选择器由 Rust 的 `craft_essence_picker` 读取当前服务器精简数据并计算推荐，前端只渲染后端返回的文字和图标。活动有效期和助战数值沿用各自数据，界面只显示满破时的加成数值。

推荐顺序：
1. 当前活动加成礼装
2. 迦勒底午茶时光（910）
3. 迦勒底午餐时光（330）
4. 贝拉·丽莎（988）
5. 蒙娜丽莎（80）
6. 其他礼装按满破时百分比牵绊加成从高到低排序

| 效果 | 简化展示 |
| --- | --- |
| 素材固定掉落 | 素材图标 +1 |
| 素材掉落百分比、活动积分 | 素材图标 掉落数 +30% |
| 活动进度 | 进度图标 活动进度 +10% |
| 伤害 | 攻击威力 +100%，区分迅/技/力指令卡、暴击、宝具 |
| 随积分变化的伤害 | 指令卡威力随活动积分变化，避免编造固定数值 |
| 敌人出现率 | 目标简称及出现率；追加出现率单独标明 |
| 友情点数 | 友情点数增加75、友情点数增加10（可叠加） |
| FSN 从者牵绊 | [FSN从者] 牵绊10% |
| 魔术礼装经验 | 魔术礼装经验增加5%、魔术礼装经验增加50（固定数量） |
| 御主经验 | 御主经验增加10%、御主经验增加50（固定数量） |
| 无条件牵绊/量子 | 牵绊点数增加5%、量子增加5% |
| 条件牵绊/量子 | [兽科] 牵绊10%、[恶]或[星] 牵绊4% |

`src-tauri/src/resources/craft_essence_bonus_labels.json` 是手动维护的 ID 映射：

- `traits` 根据已有国服礼装说明提取中文简称，并记录来源地区和礼装收藏编号；国服没有的条件按日服说明补录。所罗门分支来自日服函数条件及对应从者名称。
- 多个 `functvals` 为“或”；`overWriteTvalsList` / `script.overwriteTvals` 的同一组为“且”，组之间为“或”。界面保留这些关系。
- `rewardFunctions` 保存少量需要补充显示的关卡范围，`eventTargets` / `progressTargets` 保存敌人及进度分类简称。
- 后续新增 ID 先显示“条件#ID”，补录映射后再显示中文。

只保留当前/未来活动的索引，打开时按当前时间选择有效效果。
