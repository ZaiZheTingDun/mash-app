# 友情点确认框回归素材

- `confirmation_limited.png`：限时池确认框对应的 1920×1080 完整画面，附件 `35c54dd7-0195-4140-a5a6-4504285dea71`。
- `confirmation_regular.png`：常规池确认框对应的 1920×1080 完整画面，附件 `efef4585-5670-48a3-a9cf-85819b25f928`。

两张图片统一为 1920×1080，可直接使用生产 `cv.json` 中的 ROI 和 `templateReferenceWidth` 做完整画面回归。

确认框模板使用两个卡池共有的“自动变还设定”按钮，参考宽度为 1920，生产搜索区域为 `(0.35, 0.55, 0.3, 0.18)`。

测试在不修改生产配置的前提下，分别验证两个卡池的完整画面、1280×720 缩小图、去除动态文案后命中，以及移除按钮后不命中。

`home_limited.png`: 本地 BlueStacks 1920×1080 限时友情池截图，顶部余额已遮盖。用于任务临时主页匹配的双区域、压缩与动态字段回归。
