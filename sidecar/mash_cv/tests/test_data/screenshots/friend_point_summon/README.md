# 友情点确认框回归素材

来源：[PR #1 评审截图](https://github.com/ZaiZheTingDun/mash-app/pull/1#issuecomment-5667507706)。

- `confirmation_limited_crop.png`：限时池确认框，附件 `35c54dd7-0195-4140-a5a6-4504285dea71`。
- `confirmation_regular_crop.png`：常规池确认框，附件 `efef4585-5670-48a3-a9cf-85819b25f928`。

两张图片保留附件原始像素，均是裁剪图，不能将图片宽高当作设备分辨率。

确认框模板由限时池裁剪图的 `(left=565, top=558, right=915, bottom=634)` 提取“自动变还设定”按钮，归一化为 `380×83` 像素。以此前 PR 的 1920 参考宽度标题模板校准，附件中文字的像素比例约为 `0.92`（常规池首行文字相关系数约 `0.963`）。这只校准模板缩放，不证明完整画面的 ROI。

测试分别验证两个卡池、缩小图、去除动态文案后命中、移除按钮后不命中。生产搜索区域的完整截图验证仍待补充。

`home_limited.png`: 本地 BlueStacks 1920×1080 限时友情池截图，顶部余额已遮盖。用于任务临时主页匹配的双区域、压缩与动态字段回归。
